# 📊 LiveCharts WPF Demo (.NET Framework 4.7.2)

Демонстрационное WPF-приложение, которое показывает возможности библиотеки **LiveCharts.Wpf** для создания интерактивных диаграмм.  
Реализованы три типа диаграмм: круговая диаграмма, гистограмма и линейный график. Данные обновляются случайным образом по нажатию кнопки.

*(Замените на реальный скриншот)*

---

## 🚀 Возможности

- Круговая диаграмма (Pie Chart) – отображает доли категорий.
- Гистограмма (Column Chart) – показывает продажи по месяцам.
- Линейный график (Line Chart) – динамика температуры.
- Кнопка **«Обновить данные»** – генерирует новые случайные значения для всех трёх диаграмм.
- Автоматическое обновление интерфейса благодаря `INotifyPropertyChanged`.
- Плавная анимация при смене данных (встроенная в LiveCharts).
